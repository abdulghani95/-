# حاسبة البلوك

حاسبة بناء تعمل بدون إنترنت. تحسب عدد البلوك (20 × 40 سم) وأكياس الإسمنت وعربيات النحاتة.

- **من المساحة:** تدخل المساحة بالمتر المربع (أو الطول × الارتفاع) فتحصل على البلوك والإسمنت والنحاتة.
- **من عدد البلوك:** تدخل عدد البلوك فتحصل على الإسمنت والنحاتة.
- كل 100 بلوكة = كيس إسمنت + 3 عربيات نحاتة (قابلة للتعديل من "تعديل المقاسات والنسب").

## الرفع على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `block-calc`).
2. ارفع كل ملفات هذا المجلد إلى المستودع (زر Add file ثم Upload files).
3. من Settings ثم Pages، اختر Source: **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/block-calc/`

## الاستخدام بدون إنترنت

1. افتح الرابط مرة واحدة وأنت متصل بالإنترنت. هذا يحفظ التطبيق على جهازك.
2. بعدها يعمل بدون إنترنت.
3. لإضافته لشاشة الهاتف:
   - أندرويد (Chrome): القائمة ثم "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
   - آيفون (Safari): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

## ملاحظات

- لا يحتاج أي مكتبات أو خطوط من الإنترنت. يستخدم خطوط النظام العربية.
- يحفظ آخر أرقام أدخلتها على جهازك.
- عند تعديل أي ملف، غيّر رقم النسخة في `sw.js` (`block-calc-v1` إلى `v2`) ليتحدّث عند المستخدمين.
- لو فتحته من ملف على الجهاز مباشرة (بدون رابط)، تعمل الحاسبة لكن التثبيت كتطبيق يحتاج رابط https مثل GitHub Pages.
